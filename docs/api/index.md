# Generated API reference

The API reference is generated from XML documentation comments in the application project by DocFX.

- Use the API section in the documentation navigation after running the DocFX metadata/build pipeline.
- Public types, controllers and service methods should have accurate XML summaries and remarks.
- This generated reference complements the [technical reference](../articles/technical-reference.md), which documents cross-cutting workflows and security invariants.

Regenerate from the repository root:

```powershell
docfx docs/docfx.json
```
