# Synthetic receipt fixtures

These PNG files are original synthetic test images generated for OCR regression testing. They do not reproduce a real provider screen and contain only fictional account identifiers, amounts and transaction references.

Coverage:
- InstaPay-like English success layout
- Mobile wallet Arabic failure layout
- Mobile wallet English pending layout
- Bank transfer English success layout
- Bank transfer Arabic failure layout
- WebP decoding is tested by encoding the English success fixture to WebP at test runtime

Do not use these images as payment evidence. Do not replace them with customer receipts or third-party screenshots without explicit redistribution permission.
