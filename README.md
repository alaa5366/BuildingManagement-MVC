# نظام إدارة العمارات — نسخة C# (ASP.NET Core MVC)

هذه بداية تحويل مشروع "building-management" (JS + Firebase) إلى C# MVC،
مع الإبقاء على **نفس قاعدة بيانات Firebase** الحالية بدون أي تغيير أو ترحيل بيانات.

## ✅ اللي موجود في المرحلة 1 (الهيكل الأساسي)

- مشروع ASP.NET Core MVC (.NET 8) متصل مباشرة بـ Firestore عبر
  الحزمة الرسمية `Google.Cloud.Firestore`.
- تسجيل دخول بنفس منطق النسخة الأصلية بالظبط:
  - **Super Admin**: إيميل + كلمة مرور (من قائمة إيميلات مسموحة).
  - **Admin**: اختيار العمارة + رقم الهاتف + PIN (بيدور في مستندات
    `users` بنفس الطريقة، وبعدين يعمل تسجيل دخول بحساب Firebase Auth
    الداخلي المشتق من رقم الهاتف — نفس صيغة `adm-{...}@building.local`).
  - **Resident**: اختيار العمارة + رقم الدور + رقم الشقة + واتساب +
    PIN، وبعدين تسجيل دخول بحساب Firebase Auth الداخلي المشتق
    (`res-{...}@building.local`) — بنفس صيغة كلمة المرور تمامًا.
- الجلسة بعد الدخول بتتخزن في **Cookie** من طرف السيرفر (مش localStorage).
- إدارة العمارات (Super Admin فقط): عرض / إنشاء / حذف عمارة، وإضافة
  أدوار وشقق جديدة (مع إنشاء حساب Firebase Auth تلقائيًا لكل شقة، زي
  الأصل بالظبط).
- Models مطابقة 100% لشكل مستندات Firestore (`buildings`, `users`)
  عشان تقدر تشتغل على نفس القاعدة اللي شغالة عليها نسخة الـ JS دلوقتي.

## ⏭️ هيتضاف في المراحل الجاية (حسب الاتفاق)

نظام المحافظ والمصروفات/الإيرادات، التقارير والرسوم البيانية، فواتير
PDF + QR، التصويتات، سجل الصيانة، الإشعارات وواتساب، الباكب واستيراد
Excel، وأخيرًا PWA وتعدد اللغات.

## ⚙️ الإعداد والتشغيل

1. **Firebase**:
   - من Firebase Console → Project Settings → Service Accounts →
     Generate new private key، واحفظ الملف باسم
     `firebase-service-account.json` في جذر المشروع (بجانب .csproj).
   - من Project Settings → General، خد الـ **Web API Key** والـ
     **Project ID**.

2. عدّل `appsettings.json`:
   ```json
   {
     "Firebase": {
       "ProjectId": "your-project-id",
       "WebApiKey": "your-web-api-key",
       "ServiceAccountJsonPath": "firebase-service-account.json"
     }
   }
   ```

3. التشغيل:
   ```bash
   dotnet restore
   dotnet run
   ```
   المشروع محتاج .NET 8 SDK.

## ⚠️ ملاحظات مهمة

- الأدمن والسكان اللي متسجلين بالفعل في Firebase من نسخة الـ JS
  هيقدروا يدخلوا من النسخة دي مباشرة من غير أي تعديل، لأن صيغ
  الإيميل/الباسورد الداخلية متطابقة حرفيًا (`Services/AuthHelpers.cs`).
- إنشاء عمارة جديدة أو دور/شقة جديدة من النسخة دي بيحدّث نفس مستند
  Firestore، فتقدر تفتحه بعد كده من نسخة الـ JS بدون مشاكل.
- شاشة دخول الساكن حاليًا بتاخد "رقم الدور" و"رقم الشقة" كأرقام
  مباشرة (بدل الـ dropdown المتسلسل في الأصل) — هيتحسّن لاحقًا بإضافة
  AJAX/JS لعرض الأدوار والشقق ديناميكيًا.
- تسجيل دخول Super Admin بجوجل (Google Sign-In) مش متضمن في المرحلة
  دي — بس إيميل/باسورد شغال.
